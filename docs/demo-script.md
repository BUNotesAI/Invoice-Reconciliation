# 演示讲稿（2–3 分钟）

两个 Rinx 窗口并排：左边申请人林一，右边财务周敏。所有公司、人名、票据都是虚构的。

## 开场前准备

```sh
uv sync
python3 scripts/dev.py                      # 本机 Palpo + reimb-bot（Agent 默认用录制回放）
```

- 按 `docs/run.md`「准备 Rinx」打开两个 app；材料用 `fixtures/demo/` 的 15 个文件，补票用 `fixtures/claim/C04.pdf`、`C01.pdf`。
- 录制时不开 Makepad 遥控；兜底方案：`python3 scripts/e2e.py` 同一流程无界面跑一遍，输出逐项 `ok`。

## 备用说法（被问到时）

- **模型挂了怎么办？** 自动转规则模式，报告标「规则模式」，门禁、关联、打包、终审照常。
- **说明文字会不会乱写数字？** 模型的每句说明都由校验器逐字核对：数字、日期、状态必须来自引用的事实，编造的直接拒掉，换规则模板。
- **为什么不直接让模型填表？** 表里的每个数字都要能追溯到原件与账单；终审第七组会重读原件复核。
